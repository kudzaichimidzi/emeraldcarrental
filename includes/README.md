# Emerald Car Rental

A simple car rental web application built with PHP.

## Setup

1. Ensure XAMPP is installed and Apache/MySQL are running.
2. Place the project files in `C:\xampp\htdocs\emeraldcarrental\`.
3. Access the login page at `http://localhost/emeraldcarrental/login.php`.

## Features

- User login page
- Basic authentication (hardcoded for demo)

## Usage

- Open the login page in your browser.
- Enter username: `admin`, password: `password` to log in.
- Upon successful login, you'll be redirected to `dashboard.php` (not implemented yet).

## Troubleshooting

- Ensure PHP sessions are enabled.
- Check Apache error logs if issues occur.
